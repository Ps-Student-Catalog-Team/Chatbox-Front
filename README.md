# 🌐 Chatbox-Front

Chatbox-Front 是一套基于 Go 后端与静态前端页面构建的局域网即时通讯系统，适合家庭、办公室、学校或团队内部使用。

它提供了私聊、群聊、公共聊天室、用户管理、管理员后台、消息历史、头像与背景上传等能力，部署简单，适合快速上线一个轻量的内部通信工具。

---

## ✨ 功能特点

- 支持私聊、群聊和公共聊天室
- 基于 WebSocket 实现实时消息推送
- 支持用户注册、登录、密码重置
- 支持聊天记录加载与本地消息缓存
- 内置管理员后台，可管理用户、消息、禁言和广播
- 支持头像、背景和文件上传
- 支持桌面端和移动端自适应界面

---

## 🚀 快速启动

### 1. 准备环境

请先安装 Go 环境，推荐使用 Go 1.20 及以上版本。

### 2. 启动服务

在项目根目录执行：

```bash
go run main.go
```

服务启动后会自动监听端口 40001，并生成本地数据库文件 chat.db 以及上传目录。

### 3. 访问页面

- 用户界面： http://127.0.0.1:40001/index.html
- 管理后台： http://127.0.0.1:40001/admin.html
- 忘记密码： http://127.0.0.1:40001/forgot-password.html

如果要在局域网内访问，请将 127.0.0.1 替换为当前机器的局域网 IP。

### 4. 默认管理员账号

默认管理员密码为：

```text
admin666
```

如需修改管理员密码，可在启动后编辑配置文件 config.txt 中的 adminpassword 项。

---

## 🧱 项目结构

- main.go：Go 服务端入口，负责路由、WebSocket、数据库和管理接口
- index.html：主聊天界面
- admin.html：管理员后台
- forgot-password.html：密码重置页面
- css/：样式文件
- js/：前端脚本
- uploads/：上传文件存储目录

---

## 📦 打包为 Windows 可执行文件

如果你想生成一个可直接运行的 Windows 程序，可以执行：

```bash
go build -o chatbox.exe main.go
```

生成后的 exe 文件可直接双击运行。
